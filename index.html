🚀 Cara Pakai

Hanya 3 langkah — dari memasang relay sampai layar Host terlihat.

1

Pasang Relay

Di PC/Server yang selalu online dengan IP publik. Buka PowerShell sebagai Administrator:

Perintahpowershell -ExecutionPolicy Bypass -File install-relay-service.ps1 -Port 8443
Alamat relaycontoh: relay.contoh.com atau IP publik
Port8443 (default, otomatis dibuka di firewall)
File CAambil relay-ca.crt dari C:\ProgramData\RdpV\relay\.relay\
Kirim file relay-ca.crt ini ke semua klien yang memasang Host & Controller.
2

Pasang Host

Di PC yang layarnya mau dilihat:

LangkahKlik kanan RdpV.Host.Setup.exe → Run as Administrator
Relay hostisi alamat relay dari Langkah 1
Relay portisi port relay
Relay CAklik Pilih… → cari file relay-ca.crt

Klik Pasang Sekarang, tunggu selesai, lalu catat Device ID & Auth Token yang tampil.

Kirim Device ID & Auth Token ini ke penonton (yang pakai Controller).
3

Pasang Controller & Connect

Di PC penonton:

LangkahJalankan RdpV.Controller.Setup.exe → buka RdpV Controller
Relay hostisi alamat relay
Relay portisi port relay
Device IDdari Host (langkah 2)
Auth Tokendari Host (langkah 2)
Trusted CApilih file relay-ca.crt

Klik Connect → ✓ layar Host terlihat. Klik Disconnect saat selesai.

✨ Fitur Unggulan

Semua yang Anda butuhkan untuk remote viewing yang aman.

🔒 View-Only

Tidak ada kontrol mouse/keyboard, tidak ada transfer file — benar-benar hanya melihat.

🔐 TLS End-to-End

Semua komunikasi terenkripsi antara Host, Relay, dan Controller.

🛡️ Token Rahasia

Akses hanya dengan Device ID + Auth Token (di-hash, tidak pernah plain).

🩺 Host Indicator

Tray icon hijau saat ada penonton — tahu kapan layar sedang dilihat.

🖵 Fullscreen

Mode layar penuh, otomatis mengecualikan jendela Controller dari capture.

⚡ Auto-Start

Host & Relay berjalan sebagai Windows service, otomatis saat boot.

💬 Pertanyaan Umum

Jawaban cepat untuk masalah yang sering terjadi.

Tidak bisa connect, kenapa?

Pastikan relay host/port/CA benar, relay online, port firewall terbuka, dan Device ID/Token sesuai.

Muncul layar dalam layar (feedback loop)?

Ini terjadi saat Host dan Controller di PC yang sama. Gunakan mode Fullscreen (Ctrl+Shift+F11).

Sempat connect lalu putus?

Cek relay masih online dan Host service masih jalan: sc query RdpV.Host.

Resolusi tidak sesuai monitor?

Host mengirim resolusi native monitor. Pilih resolusi streaming di dropdown Controller sesuai kebutuhan.

Siap memantau layar dari mana saja?

Download installer, ikuti 3 langkah, dan layar Host langsung terlihat.
