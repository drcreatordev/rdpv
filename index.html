RdpV Remote Desktop

Lihat layar laptop dari mana saja, aman lewat TLS — tanpa kontrol jarak jauh — download di sini.

untuk laptop yang “ditonton”

Host

Pasang di laptop yang layarnya ingin dilihat. Berjalan diam-diam di background, ada indikator task-tray saat ada penonton.

Download Host Installer
untuk laptop penonton

Controller

Pasang di laptop yang dipakai melihat. Tampilan bersih: connect, lihat live, status & latency.

Download Controller Installer

Cara pakai

  1. Download & jalankan Host Installer di laptop yang mau ditonton (klik kanan > Run as administrator). Catat Device ID dan Auth Token yang tampil.
  2. Download & jalankan Controller Installer di laptop penonton.
  3. Buka aplikasi RdpV Controller, masukkan alamat relay + Device ID + Auth Token, pilih file relay-ca.crt (Trusted CA), klik Connect.
  4. Selesai melihat? Klik Disconnect. Laptop host akan otomatis berubah dari hijau ke normal di tray.
  5. Panduan lengkap & cara pasang relay sendiri: PANDUAN.md

Untuk operator / yang mau mandiri

Jalankan relay sendiri (Windows service, auto-start) di server/pc yang selalu online.

Download Relay (exe) Download install-relay-service.ps1
Keamanan: akses hanya lewat token rahasia milik pemilik host — tidak ada backdoor. Relay memvalidasi melalui hash SHA-256 token. Lihat PANDUAN.md untuk detail.
